# Truthfulness — three calibrated tiers (NOT a blanket "don't fabricate")

The 1-page CV is a condensation, NOT the full capability list. Judge by
experience, not by CV wording. Keep an exhaustive inventory of your real work
as a markdown mirror (e.g. `profile/cv-master.md`, generated by
`scripts/extract_master.py`) and read it + `profile/context.md` BEFORE any gap
call, keyword check, or tailoring decision. A JD keyword absent from the 1-page
CV is NOT a gap if it is in the inventory.

## TIER 1 — never claim without proof (real fabrication)

Hard technical skills needing real expertise you don't have (a programming
language you never used, "built an API from scratch" unless confirmed),
invented titles, dates, experiences, or numbers.

## TIER 2 — adopt liberally when plausible for your level/role (DEFAULT)

- **Universal office/digital tools ASSUMED KNOWN (calibrate this list to
  YOURSELF — replace the examples with your own):** e.g. Microsoft 365
  (Word/Excel/PowerPoint/Outlook/Teams), Google Workspace, SharePoint/OneDrive,
  Teams/Zoom meetings, dashboards, KPI tracking, reporting. Everyone in a
  modern office uses these; treat them as adopted unless you say otherwise.
- General business vocabulary (Excel/PowerPoint work, dashboards, KPIs,
  reporting), analyst/PM vocabulary (process improvement, workflow automation,
  requirements, stakeholder management), soft skills (team coordination,
  leadership, communication, adaptability).
- Skills your real projects demonstrate indirectly (e.g. building AI apps via
  no-code + existing APIs → "API usage/integration" is fine).

## TIER 3 — ask first

Only genuinely specialized enterprise platforms that need formal admin-level
training and that you haven't named (e.g. SAP, Salesforce, ServiceNow, AWS).
The agent must ASK with the FULL JD sentence — never bare keywords, never
silently mark a gap, never silently adopt.

## Rules

1. When in doubt → ask the user, quoting the full JD sentence.
2. A "gap" is only a TIER 1 skill the user confirms they lack.
3. Missing metrics → `[to fill]` placeholder (never invent numbers).
4. Tailoring = reorder + reword + ADOPT plausible TIER 2 terms; facts stay true.
